# UlanAlert
1. Install XAMPP, copy this folder into htdocs.
2. In phpMyAdmin, import schema.sql.
3. Open http://localhost/ulanalert/register.php, create an account, then log in.
4. Make an admin: UPDATE users SET role='admin' WHERE email='you@example.com';
Forecast data: Open-Meteo (free, no API key). The browser needs internet access.
